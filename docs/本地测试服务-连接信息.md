# 本地测试缓存服务 — 连接信息

本文记录本机已搭建好的 Redis / Memcached 测试服务，以及各种客户端可直接使用的连接字符串。

> 搭建方式见 `docker-compose.test.yml`，灌数据用 `scripts/test-redis-seed.sh` /
> `scripts/test-memcached-seed.py`，端到端验证用 `scripts/check-live-servers.mjs`。
> 连接字符串本身经 `scripts/verify-connection-strings.php` 实测可用。

## 一、服务一览

| 服务 | 版本 | 地址 | 认证 | 内存上限 | 持久化 |
| --- | --- | --- | --- | --- | --- |
| Redis | 8.10.2 | `127.0.0.1:6379` | **无密码** | 128 MB（`allkeys-lru`） | 关闭（纯内存） |
| Memcached | 1.6.45 | `127.0.0.1:11211` | 无（协议本身不支持） | 64 MB | 不适用 |

两个容器都设了 `restart: unless-stopped`，所以 Docker 或机器重启后会自动拉起；
端口只发布在 `127.0.0.1`，不对外暴露。

## 二、连接字符串

### Redis

本项目（phpCacheAdmin 桌面版）的 Redis 面板走的是 **Predis**，不是 phpredis 扩展，
因为自带 PHP 只启用了 `mbstring`/`openssl`/`pdo_sqlite`。以下两种 URI 形式都已实测可用：

| 用途 | 连接字符串 |
| --- | --- |
| 标准 URI（推荐） | `redis://127.0.0.1:6379` |
| 带库号（db 0） | `redis://127.0.0.1:6379/0` |
| 界面里填法（Connections 窗口） | Host `127.0.0.1`，Port `6379`，Username 空，Password 空，Database `0` |
| redis-cli（在容器内） | `docker exec -it cmd-test-redis redis-cli` |

### Memcached

Memcached 没有 URI 形式，客户端统一用「主机 + 端口」：

| 用途 | 连接字符串 |
| --- | --- |
| 主机:端口（推荐） | `127.0.0.1:11211` |
| 界面里填法（Connections 窗口） | Type 选 `Memcached`，Host `127.0.0.1`，Port `11211` |
| raw 协议探测（容器内） | `printf 'version\r\n' \| nc 127.0.0.1 11211` |

## 三、给本项目的环境变量形式

`scripts/check-*.mjs` 这些检查脚本从环境变量取目标，不把凭据写进仓库：

```bash
export PCA_TEST_REDIS_HOST=127.0.0.1
export PCA_TEST_REDIS_PORT=6379
export PCA_TEST_REDIS_PASSWORD=      # 当前无密码，留空
export PCA_TEST_MC_HOST=127.0.0.1
export PCA_TEST_MC_PORT=11211
```

因为这些就是默认值，实际上**不设任何变量**也能直接跑：

```bash
node scripts/check-live-servers.mjs
```

## 七、常用运维命令

```bash
docker compose -f docker-compose.test.yml up -d      # 启动
docker compose -f docker-compose.test.yml ps         # 状态（应显示 healthy）
docker compose -f docker-compose.test.yml stop       # 暂停（保留数据？否——纯内存，数据会丢）
docker compose -f docker-compose.test.yml down       # 删除容器与网络
docker compose -f docker-compose.test.yml logs -f    # 看日志

# 想临时加密码（验证认证路径）
docker exec cmd-test-redis redis-cli CONFIG SET requirepass localtest123
# 注意 CONFIG SET 不持久化，重启即失效；加密码后请同步设置 PCA_TEST_REDIS_PASSWORD
```

## 八、注意事项

- **数据不持久化**：Redis 关闭了 RDB/AOF，容器一停数据就没了，重新跑 seed 脚本即可。
- **无认证**：Redis 没有设密码。这仅适用于只绑回环的本机测试；**不要**把端口映射改成
  `6379:6379`（那样会暴露到局域网），phpCacheAdmin 官方文档也明确不建议暴露无认证实例。
- **Docker Hub 需镜像加速**：本机直连 `registry-1.docker.io` 会超时，已在
  `~/.docker/daemon.json`（`registry-mirrors`）和 `%APPDATA%\Docker\settings-store.json`
  （`RegistryMirrors`）配置了 `docker.m.daocloud.io` 与 `docker.1panel.live`。
  删除这些配置即可恢复直连。
