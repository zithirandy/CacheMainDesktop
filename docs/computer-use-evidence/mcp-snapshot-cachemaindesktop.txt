    └── window "连锁售票管理系统(试用版)版本:2021.2.4.1"
        ├── (0,0) 按钮 "还原"  [action: click]

（任务栏、桌面 Program Manager 同样有完整子树，此处从略。）

结论（实测边界）：
  1) Snapshot 的 Opened Windows 表对窗口级枚举可靠（两轮都枚举到本应用；
     重启后还观察到过期句柄与活动窗口并存的现象——枚举表可能含僵尸条目）。
  2) UI 树对本 Electron 应用止步于窗口标题，元素级为空；加
     --force-renderer-accessibility 重启后仍然为空（阴性结果，实测两次）。
  3) 原生窗口（上例连锁售票系统）可下钻到按钮级 → 空子树是 Electron/UIA
     暴露层面的问题，不是遍历器不下钻。
